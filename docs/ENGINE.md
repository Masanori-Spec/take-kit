# Engine and correctness contract

## Architecture

`src/engine.mjs` is dependency-free ESM, shared with the browser worker by static copy at build time. `src/cli.mjs` does bounded filesystem reads and exclusive-create writes. `web/app.mjs` handles UI state; every heavy parse/analyze/audition/export happens in a module worker. There is no backend, telemetry, microphone request or persistent browser storage.

The browser retains the source bytes and copies them into a fresh worker per job. Each job has a monotonically increasing serial. Replacement/Cancel terminates the old worker; mismatched replies cannot update state or trigger export. A 30-second worker deadline ends runaway work. Main-thread file reads also have serial checks and byte caps. Export is disabled while work or unapplied boundary edits are pending. Browser total peak memory is higher than the source cap because copied source, decoded PCM, rendered samples and ZIP can coexist; 32 MiB is an input cap, not a total heap promise.

Stop invalidates pending audition as well as stopping current audio. Source/settings/cut changes and page hiding stop playback and revoke its Blob URL. Download Blob URLs are revoked after three seconds. There is no service worker or application cache promise; the hosted UI needs its initial static assets. A downloaded source/build served locally has no external runtime dependencies.

## PCM parser

Require exact RIFF size == byte length - 8 and a WAVE signature. Walk each chunk from byte 12 with unsigned 32-bit lengths and a mandatory odd-size pad byte. The sum including pad must remain in the input. Unknown chunks can precede/between/follow known chunks, but there must be exactly one `fmt ` and exactly one nonempty `data`. `fmt ` accepts 16-byte PCM or 18-byte PCM with cbSize=0; more permissive variants are deliberately unsupported. A pad byte's value is not significant.

Validate PCM tag 1, 16 bits, channels 1 or 2, rate bounds, blockAlign=channels×2, byteRate=rate×blockAlign, data divisibility and duration **before** decoding PCM. Reject duplicate chunks, missing chunks, partial final headers, length bombs and trailing bytes. Read every sample with explicit little-endian DataView; typed-array alignment and host endianness are irrelevant. Parse original input byte-offset views correctly.

## Detection

For frame f, active(f) := max over channels |sample(f,c)| ≥ ceil(32768×10^(thresholdDb/20)). Supported threshold is −72 through 0 dBFS. Min silence is ceil(ms×rate/1000), at least one frame, with 0.1..2000 ms accepted. After min-silence consecutive inactive frames, emit `[firstActive,lastActive+1)`. An island at EOF is emitted. All-silence yields zero candidates. Short gaps remain part of one hit; no de-clicking, pre-roll, tail inference, transient or pitch analysis occurs.

Absolute peak gating can split a sound with a high threshold, merge strikes with a long silence setting, miss quiet attacks, and truncate decays below threshold. DC offset can keep a whole recording active. The UI warns when any channel's absolute mean exceeds 0.01 full scale, without correcting it. These are reasons to listen and edit, not claims that detection is authoritative.

## Review and processing

All ranges are integer **frames**, not interleaved sample-word offsets. UI/manifest call them frames; both stereo channels use `[start,end)`. Only included ranges must be non-overlapping. Their array order, not time order, determines sample order. IDs are safe `h` + four decimal digits and unique; ZIP paths are newly generated by ordinal and never derived from IDs or source names.

A review's input SHA-256 must match the source bytes, including its RIFF metadata. Imported reviews are structurally checked and source-bound. Included hits require boolean `reviewed:true` for export. This records an explicit user assertion, not proof of listening or trustworthy provenance in a hostile environment. Saved JSON can be edited externally.

Default gain=1 and zero fades makes cut PCM words exactly equal the source segment. Shared peak uses `29203 / maxAbs` for all included hits (or 1 for silence), targeting a conservative −1 dBFS bound. The common gain depends on every included sample, so exclusions/cut/gain/fade changes invalidate reviews when relevant. No per-hit gain is computed.

Fade-in n>1: sample frame i<n gets i/(n−1). Fade-out n>1: the final n frames get (length−1−i)/(n−1). An n=1 fade sets that endpoint to zero; n=0 does nothing. Each fade ≤ floor(rate×0.05), and fade-in + fade-out ≤ hit length. Quantize with sign(x)×floor(abs(x)+0.5), symmetric rounding away from zero at exact halves. Out-of-PCM-range results are rejected rather than clipped. No dither is added. Shared-gain ratio preservation only holds away from explicitly faded edges, within PCM16 rounding error.

## SFZ and archive

One group binds one numeric MIDI key and `seq_length=N`, with one region per `seq_position=1..N`. N≤100 follows the documented opcode ranges even though up to 128 candidates can be reviewed. `loop_mode=one_shot` is explicit, so the intended behavior is a complete strike despite note-off. Players can differ; no player compatibility is claimed.

WAVs have minimal 44-byte PCM headers, preserving channels/rate. ZIP is bounded STORE-only with safe fixed ASCII paths, duplicate-path rejection, CRC32, local headers, central directory and fixed DOS timestamp. The SHA-256 manifest avoids embedding source names/private RIFF tags. No archive import/extraction is implemented.
